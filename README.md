
# LabPulse

Smart College Laboratory Resource Manager

## Project Description
LabPulse is a web-based application developed using Python Flask, SQLite, HTML and CSS.

## Features
- Equipment Management
- Student Login
- Student Registration
- Student Portal
- Equipment Availability

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## How to Run

1. Install Python.
2. Install Flask:
   pip install flask
3. Run:
   python app.py
4. Open http://127.0.0.1:5000
